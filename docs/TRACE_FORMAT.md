# Формат трассировочного файла KVTR (Корвет, версия 1)

Файлы `*.kvt` пишет `korvet_bridge` (MCP-инструменты `trace_start` / `trace_stop`).
Формат двоичный, максимально компактный, без выравнивания. Все числа —
little-endian. Трассировка оперируется **тиками процессора** (2.5 МГц),
а не временем: одна запись на каждый шаг CPU.

## Заголовок (32 байта)

| Смещение | Размер | Поле          | Значение                          |
|----------|--------|---------------|-----------------------------------|
| 0        | 4      | magic         | `"KVTR"` (0x4B 0x56 0x54 0x52)    |
| 4        | 2      | u16 version   | 1                                 |
| 6        | 2      | u16 header_size | 32                              |
| 8        | 2      | u16 record_size | 34                              |
| 10       | 2      | u16 flags     | 0 (зарезервировано)               |
| 12       | 4      | u32 takt_hz   | 2500000 — частота CPU (справочно) |
| 16       | 8      | u64 start_cycles | тики CPU на момент включения трассы |
| 24       | 8      | u64 reserved  | 0                                 |

## Запись (34 байта) — состояние ПЕРЕД каждым шагом CPU

Запись делается перед КАЖДЫМ шагом процессора. Шагом считается и
исполнение инструкции, и подтверждение прерывания (RST-переход, 11 тиков):
для подтверждения прерывания запись содержит PC прерываемой инструкции,
а следующая запись — уже PC вектора.

| Смещение | Размер | Поле        | Описание                                        |
|----------|--------|-------------|--------------------------------------------------|
| 0        | 8      | u64 cycles  | Тики процессора с момента power_on (до шага)     |
| 8        | 2      | u16 pc      | PC исполняемой инструкции                        |
| 10       | 3      | u8 bytes[3] | Байты по адресам PC, PC+1, PC+2 (чтение через маппер **без побочных эффектов**) |
| 13       | 1      | u8 a        | Аккумулятор A                                    |
| 14       | 1      | u8 f        | Регистр флагов F (упакованный байт)              |
| 15       | 1      | u8 b        |                                                  |
| 16       | 1      | u8 c        |                                                  |
| 17       | 1      | u8 d        |                                                  |
| 18       | 1      | u8 e        |                                                  |
| 19       | 1      | u8 h        |                                                  |
| 20       | 1      | u8 l        |                                                  |
| 21       | 2      | u16 sp      | Указатель стека                                  |
| 23       | 1      | u8 iff      | Флаг разрешения прерываний (0/1)                 |
| 24       | 1      | u8 pic_irr  | PIC: регистр запросов (IRR)                      |
| 25       | 1      | u8 pic_isr  | PIC: регистр обслуживания (ISR)                  |
| 26       | 1      | u8 pic_imr  | PIC: регистр масок (IMR)                         |
| 27       | 2      | u16 timer_ch[0] | Таймер, канал 0: counting element            |
| 29       | 2      | u16 timer_ch[1] | Таймер, канал 1                                |
| 31       | 2      | u16 timer_ch[2] | Таймер, канал 2                                |
| 33       | 1      | u8 timer_out | Биты 0..2 = выходы (out) каналов 0..2           |

C-структура (`korvet_core/korvet_core/motherboard_types.hpp`):

```c
#pragma pack(push, 1)
struct mb_trace_record_t {
    uint64_t cycles;
    uint16_t pc;
    uint8_t  opcode_bytes[3];
    uint8_t  a, f;
    uint8_t  b, c, d, e, h, l;
    uint16_t sp;
    uint8_t  iff;
    uint8_t  pic_irr, pic_isr, pic_imr;
    uint16_t timer_ch[3];
    uint8_t  timer_out;
};
#pragma pack(pop)
static_assert(sizeof(mb_trace_record_t) == 34);
```

Python (структура в `korvet_mcp/korvet_trace.py`):

```python
REC_FMT = struct.Struct("<QH3s8BH4B3HB")   # 34 байта
```

## Нюансы

- **Тики, не время.** `cycles` — монотонный счётчик с `power_on`
  (power_on сбрасывает его в 0). «Запиши 3 секунды» невозможно — можно
  только «запиши N тиков» (3 секунды ≈ 7 500 000 тиков).
- **Дискретность.** `cycles` соседних записей различаются на стоимость
  шага: 4..17 для инструкций, 11 для подтверждения прерывания.
- **Остановка на breakpoint.** Последняя запись трассы может отражать
  инструкцию на точке останова — она НЕ исполнена (снимок делается до
  шага, а шаг не состоялся).
- **Power cycle во время трассы.** `cycles` начнётся заново с 0
  (счётчик привязан к power_on); `korvet_trace.py stats` помечает такие
  места как `cycle counter resets`.
- **Страницы портов.** Байты инструкции читаются «живьём» через
  маппер, но без побочных эффектов: для страниц портов возвращается
  0xFF (реальное чтение портов меняет состояние устройств). Исполняемый
  код в страницах портов не живёт, поэтому на дизассемблирование это
  не влияет.

## Буферизация и события сброса на диск

Мост держит кэш в памяти (по умолчанию 10 МиБ, параметр `buffer_bytes`)
и сбрасывает его в файл по событиям:

1. буфер заполнен (прямо из колбэка ядра, между инструкциями);
2. `trace_stop`;
3. `power_off` эмулятора (файл остаётся открытым, трасса продолжится);
4. завершение процесса `korvet_bridge` (SIGINT/SIGTERM/EOF по stdin).

`trace_stop` возвращает SHA-256 всего файла (заголовок + все записи) —
им можно верифицировать файл на диске.

## Утилита просмотра

`korvet_trace.py` (python3, только stdlib; ставится как консольная
команда `korvet-trace`):

```
python3 korvet_trace.py info  FILE
python3 korvet_trace.py view  FILE [--from-idx N] [--to-idx N]
       [--from-cycle N] [--to-cycle N] [--pc-min 0xE000] [--pc-max 0xEFFF]
       [--limit N] [--regs] [--pic] [--timer] [--json]
python3 korvet_trace.py find-seq   FILE "CALL,JP*,NOP" [--from-idx N]
       [--all] [--context N] [--json]
python3 korvet_trace.py find-pc    FILE 0xE797 [--from-idx N] [--all]
       [--context N] [--json]
python3 korvet_trace.py find-bytes FILE "C3 00 01" [--from-idx N] [--all]
       [--context N] [--json]
python3 korvet_trace.py stats      FILE [--top N] [--json]
```

Поиск последовательности: токены через запятую, сравнение с мнемоникой
инструкции; токен с `*` в конце — префикс (`J*` = JNZ/JZ/JNC/JC/JPO/JPE/
JP/JM/JMP). Пример: найти «вызов и сразу переход»:

```
python3 korvet_trace.py find-seq trace_000001.kvt "CALL,J*" --context 3
```
