## Глоссарий: сохранённые аппаратные термины

| Термин | Расшифровка | Смысл |
|---|---|---|
| ГЗУ / GZU | графическое запоминающее устройство | растровая видеопамять: 4 страницы × 3 плоскости × 16 КБ |
| АЦЗУ / ACZU | алфавитно-цифровое ЗУ | текстовый видеобуфер 1 КБ: 1024 × [символ, атрибут] |
| VIREG | видео-регистр | страница отображения, широкий шрифт, выбор шрифта |
| NCREG | регистр цвета | маски записи плоскостей ГЗУ |
| VISST | видео-статус | байт атрибута для АЦЗУ |
| ВГ93 / VG93 | КР1818ВГ93 (аналог WD1793) | контроллер дисковода |
| ИРПС | интерфейс радиальный последовательный | «компорт» Корвета (КР580ВВ51А/8251A) |
| DRVREG | регистр дисковода | выбор привода/стороны/мотора (PPI1-B) |
| CE / CR / OL | counting element / count register / output latch | официальные термины i8253 (КР580ИК53) |
| TMRINT | timer interrupt | выход прерывания таймера (IRQ5) |
| KDI | — | формат образа дискеты: 80×2×5×1024 = 819 200 байт |

## 1. Три принципа

### 1.1. Ядро не знает о хосте

Внутри `korvet_core/` нет ни одного `fopen`, `std::thread`, сокета или
вызова ОС. Всё, что требует окружения, вынесено наружу тремя
механизмами:

| Механизм | Направление | Примеры |
|----------|-------------|---------|
| **Колбэки** | ядро → хост | `mb_log_callback_t`, `SerialByteOutCallback`, `PrinterByteCallback`, `FdcPendingOpCallback`, `mb_trace_callback_t` |
| **Интерфейсы** | хост → ядро | `IFddImageAdapter` — единственный способ дать ядру образ дискеты |
| **Буферы** | хост → ядро | `load_data()` (ПЗУ/шрифт/mapper), `tape_insert_buffer()` (кассета) |

Хост сам читает файлы, сам решает, куда писать байты принтера, как
упаковывать LAN-поток в TCP-кадры и когда играть звук позиционирования
головки. Ядро лишь честно эмулирует железо и отдаёт события.

### 1.2. Время — только такты CPU

Единица времени в ядре — такт процессора (2,5 МГц). Константы:

```
TICKS_PER_FRAME = 50000   // 1/50 с гостевого времени (кадр, VBLANK)
VBLANK_TICKS    = 8170    // тактов в зоне вертикального гашения
```

Модель исполнения — **порциями**: хост вызывает `run_ticks(n)` /
`run_opcodes(n)` / `run_while(pred)` / `run_frame()`, ядро исполняет
целые инструкции (4–17 тактов) и возвращает управление. Между вызовами
состояние заморожено — идеальная модель для ИИ-агентов (MCP), отладчика
и детерминированных тестов. Позиция внутри кадра сохраняется между
вызовами: `run_ticks(30000) + run_ticks(20000)` == `run_ticks(50000)`.

### 1.3. Эталонная точность

Логика ВГ93 (дисковод), таймера i8253, PPI и видеоподсистемы —
по-строчный порт эталонного эмулятора emu80. Там, где это важно для
верификации, сохранены даже имена переменных эталона (`dsk_vg()`,
`cnt_ready_`, `dsk_count_dat_lost_`, `DiskBuf`, `reg_track_`), а в
комментариях стоят ссылки вида `vg.c case 0xA`, `timer.c:188-204`.
Русские транслитерации общего смысла при этом переведены в английские
имена (`ALL_TAKT` → `TICKS_PER_FRAME`, `prev_takt_` →
`last_processed_cycles_` и т.д.) — см. CHANGELOG.

## 2. Карта подсистем

```
                         Motherboard (фасад, singleton)
        ┌───────────┬────────────┬────────────┬────────────┬──────────┐
        │           │            │            │            │          │
      Cpu ──────► Memory ──► mapper (32×256) │          Video      Pic
     (i8080)      │    │                      │         ГЗУ/АЦЗУ   (i8259)
        │          │    └─ периферия ──► Fdc (ВГ93) ── IFddImageAdapter ──► [хост]
        │          │                 ► Ppi ×3 (i8255) ──► Timer(i8253) ──► Audio
        │          │                 ► Serial (i8251A) ◄── Keyboard (8×12)
        │          │                 ► Lan            ──► Mouse / Joystick
        │          │                 ► Printer        ──► Tape
        └──────────┴──── trace/log/diag ───────────────────► [хост]
```

- **Memory** — маппер страниц: 32 регистра × 256 страниц, типы страниц
  RAM/ROM0-2/KEYBOARD/PORTBASE/REGBASE/ACZU/GZU. Порты периферии
  замаплены в адресное пространство — гость читает ВГ93, PPI и таймер
  как память (порт `0xFBxx`).
- **Video** — 4 страницы ГЗУ × 3 плоскости × 16 КБ + АЦЗУ 1 КБ (символы
  + атрибуты), LUT-палитра 16 цветов → RGB. Рендер по dirty-флагам;
  двойная буферизация (`get_front_framebuffer()` через `shared_ptr`,
  zero-copy для GUI).
- **Audio** — синхронная кадровая модель: тики канала 0 таймера
  копятся в буфер кадра, в конце кадра Брезенхем-даунсамплинг в 441
  сэмпл (20 мс, 22050 Гц, моно, int16). Не забрал кадр — кадр потерян;
  очередь — забота хоста.
- **Fdc** — счётная (по обращениям к портам), а не времязависимая
  модель ВГ93, как в эталоне. Диск запрашивается сектором через
  `IFddImageAdapter`; сам файл образа ядро никогда не открывает.

## 3. Модель кадра

Один «кадр» = 50 000 тактов = 1/50 с гостевого времени. Граница кадра —
единственное место, где ядро производит «медленные» события:

1. `begin_frame()` — VBLANK-начало: сброс счётчика кадра, флаг VBLANK
   для PPI1-A бит 1, передача флага VISTS (обращение к АЦЗУ).
2. …исполнение инструкций (по пути: трасса, таймер, детектор
   зависаний)…
3. `end_frame()` — VBLANK-конец, IRQ4 (прерывание кадра), генерация
   звукового кадра, опрос мыши.

`run_frame()` = `execute_loop(бюджет 50000)`. `step()` — одиночная
инструкция отладчика (частичный кадр закрывается без конца кадра).

## 4. Глоссарий аппаратных терминов

Имена в коде сознательно используют обозначения реального железа
«Корвета» и документации БИС. Полный список — чтобы код читался без
постоянного обращения к справочникам.

### Общие

| Термин | Расшифровка | В коде |
|--------|-------------|--------|
| **tick** | такт CPU (2,5 МГц); 1 инструкция = 4–17 тактов | `run_ticks()`, `TICKS_PER_FRAME` |
| **ВГ93 / VG93** | КР1818ВГ93 — контроллер дисковода (аналог WD1793) | `class Fdc`, `dsk_vg()` |
| **ИРПС** | интерфейс радиальный последовательный — «компорт» Корвета (RS-232-подобный, через КР580ВВ51А) | `class Serial`, `SerialByteOutCallback` |
| **УСАПП** | универсальный синхронно-асинхронный приёмопередатчик (8251A) | `serial_read_status()` |

### Видео

| Термин | Расшифровка | В коде |
|--------|-------------|--------|
| **ГЗУ / GZU** | графическое запоминающее устройство — растровая видеопамять: 4 страницы × 3 плоскости × 16 КБ | `gzu_write()`, `gzu_planes_` |
| **АЦЗУ / ACZU** | алфавитно-цифровое ЗУ — текстовый видеобуфер 1 КБ: 1024 × [символ, атрибут] | `aczu_write()`, `aczu_` |
| **VIREG** | видео-регистр: страница отображения, широкий шрифт, выбор шрифта | `write_vireg()`, `vireg_` |
| **NCREG** | регистр цвета — управление записью плоскостей ГЗУ (маски) | `write_ncreg()`, `ncreg_` |
| **VISST** | видео-статус — байт атрибута для АЦЗУ | `visst_`, `readout_aczu_attr_read()` |
| **LUT** | палитра: 16 цветов по 4-битному коду | `lut_write()`, `readout_lut_rgb()` |

### Таймер i8253 (КР580ИК53) — официальные термины документации БИС

| Термин | Расшифровка | В коде |
|--------|-------------|--------|
| **CE / counting element** | счётный элемент — текущее значение счётчика | `timer_channel_t::counting_element` |
| **CR / count register** | регистр счёта — записанное начальное значение | `timer_channel_t::count_register` |
| **OL / output latch** | выходная защёлка для чтения CE | `timer_channel_t::output_latch` |
| **TMRINT** | выход прерывания таймера (IRQ5) | `irq_pending`, `trigger_interrupt()` |

### PPI (КР580ВВ55, i8255) и PIC (КР580ВН59, i8259)

| Термин | Расшифровка | В коде |
|--------|-------------|--------|
| **PPI1/2/3, порт A/B/C** | три микросхемы параллельных портов; в портах C — управление видео/дисками/звуком | `read_ppi1_a()…write_ppi3_c()` |
| **DRVREG** | регистр выбора дисковода (PPI1-B): мотор, сторона, привод | `write_drvreg()` |
| **IRR/ISR/IMR** | регистры PIC: запросы / обслуживание / маски | `read_irr()`, `read_isr()`, `read_imr()` |
| **ICW/OCW** | команды инициализации / управления PIC | `icw1_…icw4_`, `ocw3_` |

### Дисковод

| Термин | Расшифровка | В коде |
|--------|-------------|--------|
| **KDI** | формат образа дискеты Корвета: 80 дорожек × 2 стороны × 5 секторов × 1024 байта = 819 200 байт | `IFddImageAdapter::read_sector()` |
| **DRVREG-маппинг** | таблица «сырых» кодов приводов в реальные номера (floppy.c) | `DRV_TABLE[16]` |
| **PendingOp** | отложенная операция ВГ93 (режим реалистичных таймингов) | `fdc_pending_op_t` |
| **INTRQ/BUSY** | флаги статуса ВГ93: запрос прерывания / занятость | `get_intrq()`, `is_busy()` |

## 5. Потокобезопасность

Ядро **однопоточно**: все вызовы фасада должен делать один поток
(в korvet_qt6 — поток эмуляции, в mcp_server — последовательная
обработка запросов). Единственный потокобезопасный синглтон —
`Logger` (защищён `std::mutex`; в сборке `KORVET_SINGLE_THREADED`
мьютекс заменён заглушкой `FakeLock`). Колбэки вызываются синхронно из
цикла исполнения — они обязаны быть быстрыми и не блокировать.

## 6. Ограничения (осознанные)

- Звук — только динамик Корвета (канал 0 таймера). Нет эмуляции
  синтезаторов/ Covox.
- LAN — побайтовый порт без кадровой логики: упаковку в RS485/TCP
  делает хост.
- Дампы (`*_dump.cpp`) и `config.cpp` — host-инструменты с файловым
  I/O, в сборку ядра не входят (`KORVET_CORE_HOST_TOOLS`).
- `run_diagnostic()` и семейство — зарезервированный интерфейс,
  возвращает `MB_DIAG_SKIP` («не реализовано»).
