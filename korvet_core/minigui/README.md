# minigui — инструмент проверки ядра korvet_core

Консольный «мини-хост» для проверки эмуляции ПК8020 «Корвет» без
GUI-фреймворков. Ядро остаётся платформо-независимым: minigui — это
обычная программа хоста, которая читает файлы (ПЗУ, маппер, шрифт,
KDI-образы), гонит эмуляцию кадрами и снимает результаты.

Настоящая проверка эмуляции — **запуск гостевого ПО**: CP/M,
интерпретатор Бейсика, игры, редакторы. Headless-режим позволяет делать
это в CI без дисплея; опциональное SDL2-окно добавляет интерактив.

## Сборка

```bash
# Вместе с ядром (из корня korvet_core):
cmake -S . -B build && cmake --build build

# Опционально — интерактивное SDL2-окно (нужен libsdl2-dev):
cmake -S . -B build && cmake --build build --target minigui-sdl
```

## Использование

```bash
# Самопроверка подсистем (52 проверки: таймер, PIC, ИРПС+SERINT2, LAN,
# кассета, ММ8031 через PPI3, джойстик МД8030, ВГ93 одновибратор/
# Force Interrupt, OE/CLERR, формат посылки мыши, ...)
./build/minigui --selftest

# Загрузка CP/M из ПЗУ SHCOMP с системной дискетой:
./build/minigui \
    --rom data/rom/cpm22_shkomp.rom \
    --mapper data/rom/mapper.mem \
    --font data/rom/korvet.fnt \
    --disk 0=data/kdi/disk__system.kdi \
    --frames 900 --shot 900=boot.png --status

# Ввод команды (посимвольно с кадра 750, ENTER на 830):
./build/minigui ... --frames 1400 --type 750=DIR --key 830=ENTER \
    --shot 1400=dir.png

# Дамп звука в WAV:
./build/minigui ... --frames 10500 --type 750=KLAD --key 830=ENTER \
    --audio game.wav

# Загрузка Бейсика из ПЗУ Корвета 2.0:
./build/minigui --rom data/rom/korvet_v2.0.rom ...

# Верификация ИРПС/мыши/джойстика/LAN гостевым кодом 8080 (под CP/M):
# программа (periph_prog.hpp) читает/пишет окна 0FBxx через реальную
# шину; хост подаёт ввод и проверяет результаты в RAM. 10/10 на режим.
./build/periph_guest_test data/rom/cpm22_shkomp.rom \
    data/kdi/disk__system.kdi serial     # мышь Microsoft на ИРПС
./build/periph_guest_test data/rom/cpm22_shkomp.rom \
    data/kdi/disk__system.kdi parallel   # ММ8031 + джойстик МД8030

# Сетевое ПО: SENDER (пересылка файла в ЛВС, 1989):
./build/minigui --rom data/rom/cpm22_shkomp.rom \
    --disk 0=data/kdi/disk__system.kdi --frames 3600 \
    --type 750='SENDER EPSON.COM\n' --lan-out sender.bin --status
```

## Параметры

| Параметр | Назначение |
|---|---|
| `--rom <file>` | образ ПЗУ (korvet_v2.0.rom или cpm22_shkomp.rom) |
| `--mapper <file>` | таблица маппера памяти (mapper.mem) |
| `--font <file>` | шрифт знакогенератора, 8192 байта (2 набора) |
| `--disk <d>=<file>` | вставить KDI-образ в привод d (0..3) |
| `--frames <n>` | прогнать n кадров (1 кадр = 20 мс гостевого времени) |
| `--shot <f>=<file>` | скриншот PNG (512×256, 16 цветов) на кадре f |
| `--type <f>=<text>` | посимвольный ввод текста с кадра f |
| `--key <f>=<spec>` | нажать клавишу(и) на кадре f: имя (`ENTER`, `F1`) или `r:c` |
| `--keyup <f>=<spec>` | отпустить клавишу(и) на кадре f |
| `--mousemove <f>=<dx>,<dy>` | движение мыши на кадре f |
| `--mousebtn <f>=<b>` | кнопки мыши (бит 0 — левая, бит 1 — правая) |
| `--mousemode <m>` | режим мыши: 0=выкл, 1=ИРПС, 2=ММ8031 (параллельная) |
| `--joystick` | подключить джойстик МД8030 и подвигать (демо) |
| `--audio <file.wav>` | дамп звука (22050 Гц, 16 бит, моно) |
| `--serial-out <file>` | дамп байтов, переданных гостем по ИРПС |
| `--lan-out <file>` | дамп байтов, переданных гостем в ЛВС (LAND) |
| `--printer-out <file>` | дамп «напечатанных» байтов (после инверсии LSTINV) |
| `--lan-loopback` | замкнуть LAN-выход на вход (тест IRQ3/RRDY) |
| `--lan-addr <a>` | адрес РМУ ЛВС (1-15) |
| `--ch2-clock <m>` | канал 2 таймера: 0=HBL (по умолч.), 1=50 Гц, 2=2 МГц, 3=выкл |
| `--status` | дамп состояния подсистем в конце |
| `--tape-test` | вставить тестовый поток полупериодов в кассету |
| `--timer-irq-test` | запрограммировать канал 2 и проверить TMRINT |
| `--selftest` | 52 внутриядровых проверки (без данных) |
| `--quiet` | меньше лога |

## Файлы

| Файл | Назначение |
|---|---|
| `main.cpp` | CLI-харнесс: сценарии, скриншоты, звук, статусы |
| `guest_test.cpp` | прогон одного гостевого сценария (загрузка → команда → дамп экрана) |
| `periph_guest_test.cpp` | верификация ИРПС/мыши/джойстика/LAN гостевым кодом 8080 |
| `periph_prog.hpp` | ГЕНЕРИРУЕТСЯ scripts/gen_periph_prog.py (мини-ассемблер 8080) — не править руками |
| `sdl_window.cpp` | ОПЦИОНАЛЬНОЕ интерактивное SDL2-окно (не часть ядра) |
| `png_writer.hpp` | минимальный PNG-энкодер (RGB, zlib) |
| `wav_writer.hpp` | WAV-писатель (16 бит, моно) |
| `kbd_map.hpp` | эмпирическая карта клавиатуры ПЗУ 2.0 (латиница) |
| `fdd_adapter.hpp` | `IFddImageAdapter` поверх `std::FILE` (KDI-образы) |

## Что проверять гостевым ПО

Проверенная матрица (см. отчёт проекта):

| Программа | Диск | Что проверяет |
|---|---|---|
| CP/M 2.2 SHCOMP | ПЗУ + любая системная | загрузка ОС, полный ввод-вывод |
| DIR | disk__system | чтение каталога (многосекторные чтения) |
| Бейсик | ПЗУ 2.0 + disk__system | ПЗУ-Бейсик, ввод, вычисление PRINT |
| CHESS | disk_games1 | графика (доска), вопрос «цветной монитор?» |
| SAUCER | disk_games2 | текстовая игра (кириллица) |
| KLAD | disk_games1 | графика 7 цветов + мелодия (канал 0 таймера) |
| JUMPER | disk_games1 | графика 7 цветов |
| ABRIS | disk_abris | графический редактор (долгая загрузка + пробел); **мышь Microsoft на ИРПС** (`--mousemode 1` + `--mousemove/--mousebtn`) — редактор двигает курсор и реагирует на клик |
| FX | disk_e_editor | меню утилиты печати, ESC-коды принтера |
| **SENDER** | disk__system | сетевая пересылка файла в ЛВС (порты 0x20/0x21, кадры `01 25`/`01 70`, экранирование `23 <б^40H>`; `--lan-out` — дамп канала) |

Примечание: PROFFER.COM в наборе данных отсутствует (только DOC/HLP) —
для текстово-графической проверки используйте SHOW/DED или редакторы.

## Важно: раскладка клавиатуры

Таблица `kbd_map.hpp` откалибрована по фактическому декодеру ПЗУ 2.0
(эмпирически, вводом каждой клавиши). Линия KB05 в ПЗУ отличается от
таблиц документации: фактически `8 9 : ; , - . /` (в документации
`8 9 * + < = > /`). Кириллица требует переключения АЛФ — для кириллицы
используйте `--key r:c` с координатами матрицы.
