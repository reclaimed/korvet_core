# korvet_core — ядро эмуляции ПК8020 «Корвет»

Platform-agnostic ядро эмуляции советского персонального компьютера
**ПК8020 «Корвет»** (1985, НИИЯФ МГУ СССР): процессор
КР580ВМ80А (аналог Intel 8080) на 2,5 МГц, 64 КБ ОЗУ, графическая
подсистема ГЗУ/АЦЗУ 512×256×16 цветов, контроллер дисководов
КР1818ВГ93 и периферия на БИС серии КР580.

`korvet_core` представляет собой ядро эмуляции: CPU, память, видео, звук, дисковод, порты. 

Не знает об ОС и хосте, все общение с внешним миром -- колбэки, фасад, указатели итп.

Для работы потребуется контент файлов репозитория [https://github.com/reclaimed/korvet_data](korvet_data).

## Ключевые свойства

- **Полная изоляция от хоста.** Ни файлового I/O, ни потоков, ни сокетов,
  ни реального времени. Всё общение — через колбэки и интерфейсы
  (`IFddImageAdapter`, `set_*_callback`). Файлы открывает хост, ядро
  получает только байты.
- **Все тайминги — в тактах CPU** (2,5 МГц). Кадр = 50 000 тактов (50 Гц),
  звук — тики канала 0 таймера. Реального времени в ядре нет ни на одном
  уровне — «сколько ждать» решает хост.
- **Портируемость.** Компилируется под Linux/Windows; для bare-metal
  (RP2040/STM32) есть опция `KORVET_SINGLE_THREADED` — сборка без
  `std::mutex` (логгер работает без потоков).
- **Эталонная точность.** Логика ВГ93, таймера, PPI и видеоподсистемы —
  построчный порт эталонного эмулятора (emu80): имена внутренних
  переменных диспетчера (`dsk_vg`, `cnt_ready_`, `reg_track_`…) сохранены
  для верификации построчно.
- **Отложенные операции ВГ93** (PendingOp) — опциональный режим с
  реалистичными таймингами дискеты для GUI (звуки, светодиод), при этом
  по умолчанию поведение побитово идентично эталону (мгновенное
  выполнение) — см. [docs/FDC_PENDINGOP.md](docs/FDC_PENDINGOP.md).

## Эмулируемое железо

| Узел | БИС | Модуль ядра |
|------|-----|-------------|
| CPU | КР580ВМ80А (i8080), 2,5 МГц | `i8080/` (standalone) + `internal/cpu/` |
| ОЗУ/ПЗУ + маппер страниц | 64 КБ RAM, 8–24 КБ ROM, 32x256 рег/стр | `internal/memory/` |
| Видео ГЗУ/АЦЗУ | 512×256, 16 цветов, 4 страницы графики, 1 страница текста | `internal/video/` |
| Таймер | КР580ИК53 (i8253), 3 канала | `internal/timer/` |
| Контроллер прерываний | КР580ВН59 (i8259) | `internal/pic/` |
| Параллельные порты | 3 × КР580ВВ55 (i8255) | `internal/ppi/` |
| Дисковод | КР1818ВГ93 (WD1793), 4 привода | `internal/fdc/` |
| Последовательный порт | КР580ВВ51А (i8251A), «ИРПС» | `internal/serial/` |
| Локальная сеть | побайтовый порт LAN | `internal/lan/` |
| Принтер | порт LST (0x30–0x38) | `internal/printer/` |
| Клавиатура | матрица 8×12 | `internal/keyboard/` |
| Магнитофон | кассетный интерфейс | `internal/tape/` |
| Мышь/джойстик | через PPI3/ИРПС | `internal/mouse/`, `internal/joystick/` |
| Звук | динамик от канала 0 таймера, 22050 Гц | `internal/audio/` |

## Быстрый старт

```bash
# Ядро как статическая библиотека (+ демо)
cmake -S korvet_core -B build-core && cmake --build build-core
./build-core/core_demo          # пример инициализации (данные не входят в репозиторий)

# Опция для bare-metal (без <mutex> в рантайме)
cmake -S korvet_core -B build-core -DCMAKE_CXX_FLAGS="-DKORVET_SINGLE_THREADED=1"
```

Минимальное подключение (хост читает файлы сам):

```cpp
#include "korvet_core/motherboard.hpp"

auto& mb = korvet::Motherboard::get_instance();
korvet::mb_config_t cfg{};              // разумные дефолты
mb.init(&cfg);
mb.load_data(rom, rom_size, mapper, mapper_size, font, font_size);
mb.power_on();
auto res = mb.run_ticks(50'000);        // один кадр (50 Гц)
```

Дальше — [docs/MOTHERBOARD_API.md](docs/MOTHERBOARD_API.md) (справочник
фасада) и [docs/EXAMPLES.md](docs/EXAMPLES.md) (реальные интеграции из
korvet_qt6: звук, видео, диски, озвучивание дисковода, трассировка).

```
    ├── EXAMPLES.md            ← примеры интеграции (цитаты korvet_qt6)

```

## Сборочные опции CMake

| Опция | По умолчанию | Описание |
|-------|--------------|----------|
| `KORVET_CORE_HOST_TOOLS` | `OFF` | Собрать host-утилиты ядра (`internal/config/config.cpp` — файловый I/O; в ядро не входит) |
| `KORVET_SINGLE_THREADED` | — | Макрос компиляции: логгер без `std::mutex` (bare-metal RP2040/STM32) |

Требования: CMake ≥ 3.16, компилятор C++17. Внешних зависимостей нет.
