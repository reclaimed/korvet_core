# CHANGELOG — korvet_core

## 0.2.0 (2026-10-15) — английские имена API + документация

**Ломающее изменение** для хостов, использующих переименованные
публичные символы (внутри семейства korvet_qt6/korvet_mcp обновлены
синхронно; прочие хосты — см. таблицу).

### Удалено мёртвое

- `Timer::mute_flag_` (нигде не читался), объявления без определений
  `test_audio_integration()`, `test_all_modes_with_interrupts()`,
  `update_output()`.

### Комментарии

- ~420 английских комментариев переведены на русский по всему ядру
  (включая dump-утилиты и i8080). Цитаты и закомментированный код-история сохранены как есть.
- Исправлен `-Wmisleading-indentation` в `keyboard.cpp`.

### Документация (новая)

- `README.md` — общее описание, железо, быстрый старт, структура.
- `docs/OVERVIEW.md` — принципы ядра, карта подсистем, глоссарий.
- `docs/MOTHERBOARD_API.md` — полный справочник фасада.
- `docs/EXAMPLES.md` — интеграции с цитатами кода korvet_qt6: звук,
  видео, диски, озвучивание дисковода, цикл реального времени,
  трассировка, клавиатура, порты.

## 0.1.1

- Сборка host-утилит вынесена в опцию `KORVET_CORE_HOST_TOOLS`
  (по умолчанию OFF): `config.cpp` (файловый I/O) и `*_dump.cpp`
  не входят в ядро.

## 0.1.1

- Platform-agnostic аудит: из ядра убраны `<thread>`, файловый I/O и
  реальное время; опция `KORVET_SINGLE_THREADED` для bare-metal;
  демо `main.cpp` → `examples/core_demo.cpp`.

## 0.1.1

- Трассировка исполнения (`mb_trace_record_t`, KVTR v1), точное
  управление исполнением `run_ticks/run_opcodes/run_while`,
  детектор зависаний, колбэк логирования.

## 0.1.0

- Базовая реализация всех подсистем: CPU (standalone i8080), память с
  маппером, ГЗУ/АЦЗУ, таймер i8253, PIC, PPI, ВГ93 с отложенными
  операциями, ИРПС, LAN, принтер, клавиатура 8×12, мышь, джойстик,
  кассета, кадровая аудио-модель.
